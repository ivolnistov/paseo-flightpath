# Paseo Flightpath

Flightpath is organized around three Paseo plugins.

| Plugin | Responsibility | Repository directory |
| --- | --- | --- |
| Roadmap | Maintains the project's work list. | [roadmap](roadmap/) |
| Plan | Turns a work item into a plan, breaks it into tasks, and records their dependencies and acceptance criteria. | [plan](plan/) |
| Pipeline | Executes the approved plan through a configured workflow. It runs agents and checks, manages reviews and rework, and records execution results and history. | [pipelines](pipelines/) |

An approved plan revision is the handoff from Plan to Pipeline.
